# Cyanosite/homebrew-tap

Homebrew formulae for my tools.

| Formula | Description |
| --- | --- |
| [`uikit-init`](https://github.com/Cyanosite/uikit-init) | Scratch pure-UIKit iOS app (programmatic UI, no storyboards), generated by Xcode's template engine |

```sh
brew install cyanosite/tap/uikit-init
```

The fully-qualified name taps and trusts the formula in one step. If you `brew tap cyanosite/tap`
separately instead, Homebrew 6+ also needs `brew trust cyanosite/tap` before installing.
