# Cyanosite/homebrew-tap

Homebrew formulae for my tools.

```sh
brew tap Cyanosite/tap
```

| Formula | Description |
| --- | --- |
| [`uikit-init`](https://github.com/Cyanosite/uikit-init) | Scratch pure-UIKit iOS app (programmatic UI, no storyboards), generated by Xcode's template engine |

```sh
brew install uikit-init
```
